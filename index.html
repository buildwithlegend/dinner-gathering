如何把計算器變成離線手機 App？

✓ 內建離線快取與自動記憶功能

只要開啟過一次，系統會自動快取網頁與記憶您上次輸入的尺寸；在沒有網路的工地現場也能 100% 正常使用。

步驟 1 將此 HTML 檔案轉為網頁連結

將下載的 INDEX.html 上傳至免費靜態空間，即可獲得一組專屬網址。

iPhone iOS Safari 加入主畫面

用 Safari 打開網址 → 點擊底部中間的分頁圖示 → 往下滑選擇加入主畫面，桌面即會出現獨立全螢幕 App 圖示。

Android / 電腦 Chrome 安裝應用程式

用 Chrome 打開網址 → 點擊右上角選單 → 選擇安裝應用程式。
